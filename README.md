## Abstract

**LifeLink – Emergency Blood & Medicine Network** is a web-based healthcare assistance platform designed to provide quick access to essential medical resources during emergency situations.

The platform connects **patients, blood donors, volunteers, and pharmacies** in one centralized system. Users can register as donors or volunteers, search for blood donors based on **blood group and location**, and create emergency blood requests with details such as blood group, units required, hospital, location, urgency, and contact information. Requests can be tracked through stages such as **Open, Accepted, In Progress, and Completed**.

LifeLink also provides a **Medicine Finder** to search for required medicines and available pharmacies, including their location and contact details. Google Maps API can be integrated to support nearby donor and pharmacy discovery.

The application uses **Java, JSP, HTML5, CSS3, JavaScript, MySQL, JDBC, Apache Tomcat, REST APIs, and Git/GitHub**. The project follows **Agile Scrum methodology**, with Jira used for sprint planning and task tracking.
